# Шифратор/дешифратор файлов в папке

Консольное приложение на C++ с использованием Qt и OpenSSL для шифрования и дешифрования файлов в папке с помощью алгоритма AES.

---

## 1. Постановка задачи

Реализовать защиту данных пользовательских папок и файлов, находящихся в папке, а также подпапках, путем шифрования. Для доступа к данным исходной папки необходимо выполнить дешифрование.

**Требования к реализации:**
- Язык: C++
- Основной класс шифрования/дешифрования реализован как **Singleton**
- Входные данные: путь к папке, пароль для шифрования/дешифрования
- Использование библиотеки Qt для работы с файловой системой
- Использование AES-256 для шифрования

---

## 2. Предлагаемое решение

### 2.1 Общая идея

Пользователь указывает путь к папке, выбирает действие (шифрование или дешифрование) и вводит пароль. Программа обходит все файлы в указанной директории рекурсивно и для каждого файла выполняет следующие действия:
- Проверяется на необходимость шифрования (не системный, не ярлык, не исполняемый)
- Шифруется алгоритмом AES с уникальной солью  
- В начало файла добавляется метка "ENCRYPTED" и соль
- При дешифровании метка и соль считываются, файл расшифровывается

Для шифрования используется симметричный алгоритм AES-256, который обеспечивает высокий уровень защиты данных при условии, что пароль хранится в тайне.  

### 2.2 Структура решения

Решение основано на трех классах:

#### 2.2.1 Класс ICryptTool(интерфейс)

Это абстрактный базовый класс, который определяет контракт для всех инструментов шифрования.  
Предназначен для обеспечения возможности замены алгоритма шифрования без изменения остального кода.

#### 2.2.2 Класс AesCryptTool(основной класс шифрования)  

Этот класс реализует интерфейс ICryptTool и предоставляет конкретную реализацию шифрования, а именно обход папки и её подпапок, и шифрования каждого встреченного файла. Класс реализован с использованием паттерна **Singleton(одиночка)**, что гарантирует наличие только одного экземпляра в программе.
Предназначен для шифрования и дешифрования файлов в папке с использованием AES.  

#### 2.2.3 Класс CryptFileDevice  

Сторонний компонент, предоставляющий класс для шифрования/дешифрования файлов с использованием  алгоритма AES и библиотеки OpenSSL. Используется в  качестве низкоуровневого криптографического модуля. Он выполняет фактическое шифрование/дешифрование,  в то время как класс AesCryptTool реализует высокоуровневую логику: рекурсивный обход папок, проверку файлов, управление солью и метками.  
Источник: https://github.com/alexeylysenko/CryptFileDevice  
Автор предоставляет лицензию для свободного использования.

| C++ compiler | C++11 |

### Использование

Программа работает в интерактивном режиме через консоль. Пользователю последовательно предлагается:

1. Ввести путь к папке

2. Выбрать действие (1 — шифрование, 2 — дешифрование)

3. Ввести пароль

## 4. Тестирование

### Входные данные - путь до папки, пароль

### Тестирование функции ШИФРОВАНИЯ папки (encryptFolder)

**Случай 1**: Папки по пути не существует.  
 Результат: Программа ничего не делает, завершается с выводом сообщения о том, что такого пути не существует.  

**Случай 2**: Папка по переданному пути существует и пуста.  
Результат: Программа ничего не делает, завершается с пустым выводом.  

**Случай 3**: Папка по переданному пути существует, содержит подпапки и файлы.  
Результат: Программа шифрует файлы, выводится список зашифрованных файлов.  

**Случай 4**: Папка содержит файлы разных типов.  
Результат: Программа шифрует все типы файлов.  

**Случай 5**: Папка содержит пустые файлы.  
Результат: Программа пропускает пустые файлы, выводится соответствующее сообщение.  

**Случай 6**: Папка является системной.  
Результат: Программа не производит шифрование, выводится соответствующее сообщение.  

**Случай 7**: Папка содержит уже зашифрованные файлы.  
Результат: Программа пропускает зашифрованные файлы, выводится соответствующее сообщение, остальные файлы шифруются как обычно.  

**Случай 8**: Пустой пароль.  
Результат: Программа не производит шифрование, выводится сообщение, что пароль не может быть пустым.  

### Тестирование функции ДЕШИФРОВАНИЯ папки (decryptFolder)

**Случай 9**: Папка содержит зашифрованные файлы, введен верный пароль.  
Результат: Программа расшифровывает файлы.  

**Случай 10**: Папка содержит незашифрованные файлы.  
Результат: Программа пропускает незашифрованные файлы, зашифрованные файлы дешифруются как обычно.  

**Случай 11**: Неверный пароль.  
Результат: Программа не выполняет дешифрования, выводится сообщение о некорректном паролем.  

**Случай 12**: Пустой ввод пути.  
Результат: Выводится сообщение о пустом вводе.  

Тестовые примеры расположены в папке "tests".
